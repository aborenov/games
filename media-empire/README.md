# Первая полоса

Одна газетная стратегия: Белфорд, 1900 год, двенадцать еженедельных выпусков.
Город состоит из объёмных зданий, улиц, транспорта и живых состояний.
Редакционные решения меняют не только деньги и доверие, но и участников города.

## Как играть

1. Выберите среди трёх городских тем. На выпуск есть восемь рабочих часов:
   короткая заметка занимает два, проверенный репортаж — четыре.
2. Назначьте первую полосу из полученных материалов, цену, тираж и доставку.
3. Напечатайте газету. Отчёт объяснит продажи, все расходы, доверие и последствия.
4. Арендуйте рекламу на трамвае или речной линии, выполните срок и охват заказа.
5. Развивайте редакцию: киоск открывает канал продаж, печать снижает расходы,
   второй стол добавляет время. Стройка появляется на карте.

Проверенный репортаж о пожаре закрывает опасный цех; последующий акт ремонта
открывает его. Рабочие, управа и торговцы реагируют по-разному. Закрытие меняет
пассажиропоток и рекламный охват. Снег и ограниченная навигация требуют менять
доставку. Публикация критики фабрики может прекратить её спонсорский договор.

Цель главы: двенадцать номеров, 5 000 постоянных читателей, доверие 70 и шесть
проверенных опубликованных материалов. Это авторская кампания, не бесконечная
песочница. Политические отношения реализованы тремя сторонами; выборы как
самостоятельная симуляция и бюджеты всех городских предприятий не заявляются.

## Запуск и проверки

Node.js 24, npm. React 19, TypeScript, Vite 7, Three.js 0.187.

    npm ci
    npm run dev -- --host 0.0.0.0 --port 4173 --strictPort

    npm test
    npm run check
    npm run build
    npm run preview -- --port 4174 --strictPort

Браузерные сценарии требуют Python, Playwright, Pillow и Chromium:

    python3 -m pip install playwright pillow
    python3 -m playwright install chromium
    GAME_URL=http://127.0.0.1:4174/ python3 tests/browser_rebuild.py
    GAME_URL=http://127.0.0.1:4174/ python3 tests/browser_campaign.py
    GAME_URL=http://127.0.0.1:4174/ python3 tests/browser_offline.py

Можно указать CHROMIUM_PATH и QA_OUTPUT_DIR. По умолчанию Chromium находится
в /usr/bin/chromium. Для жестов нужны touch/CDP, для WebGL в headless-сценариях
используется SwiftShader. Это не тест физических iPhone/Android.

Сравнение экономических путей:

    node --import tsx docs/rebuild/simulation/strategies.mjs

[Расчёты и границы баланса](docs/rebuild/simulation/RESULTS.md).
Результаты тестовой стратегии не обещают прибыль каждой партии.

## Устройство

- src/simulation: чистые правила, авторские темы, контракты, бухгалтерия,
  отношения, стадии зданий и строгий перенос партии.
- src/city: самостоятельные геометрические модели, планировка, общие пути,
  трафик, камера, проекция меток, качество и очистка GPU-ресурсов.
- src/ui: редакционная полоса, прогноз/печать, договоры, газета, настройки.
- src/App.tsx связывает состояние игры и представление; renderer не считает деньги.

Мир не использует картинку города как поверхность. Свет, перспектива, глубина,
выбор, фабрика/стройка и реклама относятся к настоящим объектам. Подписи —
отдельный интерфейс. Для нового города нужна своя планировка и состав объектов;
меню выбора городов в текущей главе отсутствует.

Экономный режим ограничивает DPR и тени, число людей/частиц. Скрытая вкладка
останавливает сцену; отключение движения замораживает анимацию, но сохраняет
ручное управление камерой. Доступен список мест для навигации без жестов.
Измеренного FPS, температуры и расхода батареи на физических телефонах пока нет.

## Сохранения и мобильная установка

Новая схема: first-page, версия 2. Ключ first-page-v2 хранится отдельно от
прежнего прототипа; его данные не удаляются и доступны для скачивания.
Импорт проверяет структуру и причинную согласованность. Явная замена создаёт
резервную копию; старые и чужие записи вкладок отклоняются.

PWA работает без сети после первой полной загрузки по HTTPS. Офлайн-пакет
содержит код, шрифты и оригинальные иллюстрации. В capacitor.config.ts сохранена
конфигурация для нативной упаковки; APK/IPA не собирались.

## Аудит и графика

[Аудит исходной работы](docs/AUDIT_2026-11-16.md) зафиксирован коммитом d62fd56
до пересборки. Сравнение с News Tower, Mini Motorways и Pocket City 2 основано
на официальных материалах; платные игры лично не проходились.

Городские модели созданы в проекте. Три газетные линогравюры — оригинальные
сгенерированные растры. Чужие эталонные изображения находятся только в аудите.
Иконки Phosphor. Локальные Manrope и Cormorant Garamond: лицензии в public/fonts/.
Проверка кода, наблюдаемое качество и ещё не проверенный игровой опыт описаны
отдельно в [отчёте пересборки](design-qa.md).

Дополнительные проверки исходных дефектов в dev-сборке:

    GAME_URL=http://127.0.0.1:4173/ python3 tests/browser_boundaries.py

Они проверяют жесты поверх меток, Enter, отложенные сброс/импорт, отказ
хранилища/WebGL и восстановление повреждённого файла. Для записи игрового пути
задайте RECORD_VIDEO=1 при запуске browser_rebuild.py; требуется ffmpeg Playwright.
