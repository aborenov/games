# Газетная империя

Мобильная веб-игра на Phaser 4, React и TypeScript. Первая глава: 12 выпусков
в Белфорде 1900 года.

## Геймплей

1. Откройте событие, отправьте репортёра, проверьте два источника.
2. Выберите шесть материалов и первую полосу.
3. Назначьте цену, тираж, доставку и рекламодателей.
4. Напечатайте номер, получите фактический отчёт и прочитайте газету.
5. Вернитесь в изменившийся город и вложите заработок в развитие.

Киоск строится за один выпуск и увеличивает охват. Восстановление типографии
занимает два выпуска и снижает расходы. Банк закрывается на проверку.
Конкуренты меняют цены и тираж; погода и стоимость бумаги влияют на экономику.
Цель: 12 номеров, первое место по продажам и доверие не ниже 75.

## Запуск

Node.js 22.12+; проверено на Node.js 24.

    cd media-empire
    npm ci
    npm run dev -- --host 0.0.0.0 --port 4173 --strictPort

    npm test
    npm run build
    npm run preview -- --port 4174 --strictPort

Сборка находится в dist/. Скрипт сборки создаёт версионированный service worker
с полным офлайн-пакетом. PWA требует HTTPS; локально используется localhost.
После первой загрузки игра может открываться и выпускать газеты без сети.

В capacitor.config.ts подготовлена конфигурация нативной упаковки.
APK/IPA в этой версии не собирались.

## Сохранение

Партия сохраняется целиком: номера, расследования, здания, экономика,
конкуренты и настройки. Есть экспорт и импорт JSON. Несовместимый файл
отклоняется до изменения партии. Повреждённые локальные данные сохраняются
отдельно для скачивания. Схема: media-empire-mobile, версия 1.
Сохранения прежних прототипов используют отдельные ключи.

## Проверка в браузере

Нужны Python, Playwright и Chromium:

    python -m pip install playwright
    python -m playwright install chromium
    GAME_URL=http://127.0.0.1:4174/ python tests/browser_playthrough.py
    GAME_URL=http://127.0.0.1:4174/ python tests/browser_offline.py
    GAME_URL=http://127.0.0.1:4174/ python tests/browser_regressions.py

Можно указать CHROMIUM_PATH и QA_OUTPUT_DIR; по умолчанию используется
/usr/bin/chromium и test-results/. Первый сценарий проходит репортаж,
строительство, газету, перенос сохранения, ошибочный импорт, жест
масштабирования и все 12 выпусков. Второй проверяет production-сборку без сети.

[Результаты и сравнение с дизайном](design-qa.md). Проверены Chromium с
touch-вводом и ширины 360, 390 и 430 CSS px. Целевой лимит сцены — 60 кадров/с;
измерения на физических iPhone и Android ещё нужны.

## Графика

Карта, транспорт, киоск, портрет, иллюстрация репортажа, бумага и миниатюра
газеты — сгенерированные растровые ресурсы. Транспорт и пар анимирует Phaser.
Иконки: Phosphor Icons. Шрифты: локальные Manrope и Cormorant Garamond;
лицензии OFL находятся в public/fonts/.

## Большой город

Карта 1536 × 1024 нарисована без надписей и подвижных объектов. Камеру можно
двигать и масштабировать; «План города» переносит к редакции, рынку, вокзалу,
ратуше, фабрике и другим местам. В карточках указаны владельцы, интересы и
рекламные площадки. [Бизнес, власть и будущие контракты](docs/CITY_SYSTEMS.md).

Данные города находятся в src/world/belford.ts. Новый CityDefinition задаёт
рисунок, камеру, подписи, здания, области нажатия, маршруты, остановки и трубы;
CityScene менять не требуется. Транспорт и пешеходы используют собственные
атласы, движение по длине пути и единые часы. Выключение анимации замораживает
все слои. Сохранения газетной главы остаются совместимыми.

Для проверки камеры и акторов нужен dev-сервер:

    GAME_URL=http://terminal.local:4173/ python tests/browser_world.py

Для записи видео дополнительно установите Playwright ffmpeg и задайте
RECORD_VIDEO=1. [Запись браузерного сценария](docs/city-motion.mp4).
Рекламные договоры с перевозчиками и отдельные бюджеты предприятий пока
не реализованы; карточки описывают устройство города и направление развития.
